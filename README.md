# homebrew-tap

Homebrew formulae for [lig](https://github.com/KevenGoncalves/lig), Fig-style autocomplete
for zsh, bash and fish. Works on Apple Silicon macOS and on Linux (x86_64 and ARM64).

```bash
brew install kevengoncalves/tap/lig
lig install
```

`Formula/lig.rb` is updated by lig's release workflow on every release.
